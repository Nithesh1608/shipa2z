# Contributing to shipa2z

Thanks for helping vibecoders ship with fewer faceplants.

## Ground rules
- Keep templates **generic** — no private app source, no real credentials, no customer data.
- Prefer small PRs: one lane (QA / security / UI / docs).
- Document “why” in the PR body (vibecoders skim).

## Ideas we want
- Next.js / SvelteKit / Remix adapter notes
- GitHub Action that runs the public matrix on PRs
- More device presets / WebKit notes for macOS CI
- Better Strix CI examples
- Translations of the checklists

## Local
```bash
npm i
# templates are docs — run them inside a real app
```
